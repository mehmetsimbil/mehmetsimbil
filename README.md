# Mehmet Şimbil

Software Developer focused on building enterprise applications, backend systems and modern web platforms with the .NET ecosystem.

I work on production applications involving complex business rules, system integrations, background processing, search/indexing and modern frontend technologies.

## 👨‍💻 About Me

- 💻 Working primarily with **C#, .NET and ASP.NET Core**
- 🏢 Building enterprise applications with **ASP.NET Core MVC, REST APIs and Entity Framework Core**
- 🏗️ Applying **Clean Architecture, CQRS and MediatR** in modern .NET applications
- 🎨 Developing frontend applications with **Angular**, **Next.js** and **React**
- ⚡ Building asynchronous workflows with **RabbitMQ and MassTransit**
- 🗄️ Working with **SQL Server and PostgreSQL**
- 🔎 Experienced with **search, indexing and data synchronization workflows**
- 🔌 Developing **external API, ERP and third-party system integrations**
- ⚙️ Building **background services, scheduled jobs and queue-based processing**
- 🔐 Working with **authentication, authorization and JWT-based APIs**
- 🐳 Using **Docker and Docker Compose** for development and containerized environments
- 🧪 Working with automated testing and **Playwright** in modern web applications
- 🚀 Focused on maintainability, performance, scalability and reliable business workflows

> Most of my production work is private due to confidentiality.  
> The public repositories on this profile are independent projects created from scratch to demonstrate the technologies, architectural patterns and engineering practices I work with without exposing proprietary source code, business logic or data.
